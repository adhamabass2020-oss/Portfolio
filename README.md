## 💻 Running the Portfolio Locally

Since this site is built using standard, standards-compliant HTML5, CSS3, and modern vanilla JavaScript, no heavy Node.js or build steps are required.

### Method 1: Instant Python HTTP Server
Open your terminal inside this project directory:
```powershell
python -m http.server 8000
```
Then visit: `http://localhost:8000`

### Method 2: Direct File Open
Double click `index.html` or open it with any web browser (Chrome, Edge, Firefox, Brave).
